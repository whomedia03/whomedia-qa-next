# WHOMEDIA QA · 새 독립 버전

기존 QA-Inspection-System 코드를 가져오지 않고 새로 구성한 대학 강의 영상 검수 앱입니다.
관리자·로그인 화면은 파란 프레임·반투명 카드·동심원 그래픽과 확대된 글꼴을 사용합니다. 외부 심사위원에게는 큰 글자, 흰색 본문, 남색 메뉴로 구성한 별도의 읽기 화면을 제공합니다. `src/design2-theme.css`는 공통 파란 테마, `src/space-theme.css`는 기본 관리자 레이아웃, `src/evaluator.css`는 외부 검수 화면, `src/SpaceTheme.tsx`는 자체 벡터 그래픽을 관리합니다. 참고 디자인의 원본 이미지나 워터마크는 배포 파일에 포함하지 않았습니다. 모달에서는 Tab 키로 포커스를 순환하고 Escape로 닫을 수 있습니다.
2026-11-04 npm 레지스트리에서 확인한 React 19.3.1, Vite 8.3.5, TypeScript 7.0.2, Vercel Blob 2.8.2를 사용합니다. 실제 설치 버전과 잠금 파일을 포함했습니다.

## 가장 쉬운 설치 순서

1. GitHub에서 새 비공개 저장소를 만듭니다. 이 폴더의 파일을 올립니다. 기존 저장소와 운영 서비스는 유지합니다.
2. Vercel에서 **Add New → Project → 새 GitHub 저장소 Import**를 선택합니다. Framework는 Vite, Node.js는 24.x입니다. 빌드 명령과 출력 폴더는 `vercel.json`에 있습니다.
3. Vercel 프로젝트의 **Storage → Create Database / Store → Blob**에서 **Private** 저장소를 생성하고 이 프로젝트에 연결합니다. 공개 저장소를 만들지 마세요. `BLOB_READ_WRITE_TOKEN`이 자동 생성됩니다. 화면 명칭은 Vercel 업데이트에 따라 달라질 수 있습니다.
4. **Settings → Environment Variables**에 `ADMIN_PASSWORD`, `SESSION_SECRET`을 각각 32자 이상인 서로 다른 임의 문자열로 추가합니다. 관리자 비밀번호를 저장소에 올리거나 `VITE_` 접두어를 붙이지 마세요. 비밀번호 관리자에서 생성하는 것이 간단합니다.
5. 필요하면 `PUBLIC_APP_URL=https://새프로젝트.vercel.app`을 설정합니다. 미설정 시 Vercel이 제공하는 프로덕션 주소를 QR에 사용합니다. 환경 변수는 Production과 사용하려는 Preview 환경에 적용한 뒤 **Redeploy**합니다.
6. `https://새프로젝트.vercel.app/admin`에서 로그인합니다. **프로젝트 만들기 → 영상 등록 → 제출 링크·QR** 순서로 사용합니다.

검수자는 발급된 전용 링크로 로그인 없이 접속합니다. 링크에 포함된 토큰도 함께 전달해야 합니다. 단순히 `?p=postech`만 입력해서는 접근할 수 없습니다. 기관 링크는 그 기관만, 개별 링크는 지정된 영상만 반환합니다. 링크 유효기간은 90일이며 만료 전에 새로 발급하세요. `SESSION_SECRET`을 바꾸면 기존 링크와 로그인 세션이 모두 무효화됩니다.

제출 링크는 관리자 로그인 쿠키가 있는 브라우저에서도 기관·영상 범위를 우선 적용합니다. 다른 기관의 이름·카테고리·영상·검수 기록은 조회 응답에 포함하지 않으며 관리자 메뉴도 표시하지 않습니다. 기관/영상 파라미터나 토큰을 변경하면 권한을 다시 검증합니다. `/admin` 주소는 내부 관리용이며 외부에는 반드시 발급된 링크를 전달하세요.

배포 후 검수자가 접속할 수 있도록 Vercel 프로젝트의 Deployment Protection 설정을 확인하세요. 이 앱은 별도의 관리자 로그인과 검수 링크 검증을 제공합니다.

## 포함 기능

- 기관 프로젝트 생성 / 주차·차시 영상 등록
- 최대 2GB 실제 영상 직접 업로드, 서버에 파일 메타데이터 저장
- 비공개 영상 재생 및 타임코드 의견, 승인·수정 요청
- 기관별 / 개별 영상별 링크와 1600px QR PNG 다운로드
- 검수 현황 집계, 활동 기록, CSV 결과 내보내기
- 관리자 로그아웃, 영상 원본·등록 정보 삭제
- 한국어 반응형 화면, 가짜 영상·샘플 데이터 없음

MP4(H.264/AAC)를 권장합니다. MOV·MKV·WebM은 브라우저 코덱 지원에 따라 재생이 안 될 수 있습니다. 이 앱은 변환·트랜스코딩을 하지 않습니다.

## 단순한 저장 구조

Vercel Blob **한 개**에 다음을 저장합니다. Firebase, AWS 설정, 외부 DB, 별도 로그인 서비스가 필요하지 않습니다.

```text
projects/{기관ID}.json                    기관 정보
videos/{기관ID}/{영상ID}.json             영상 정보
media/{기관ID}/{영상ID}.mp4               실제 원본 (형식에 따라 확장자 변경)
reviews/{기관ID}/{영상ID}/{의견ID}.json    검수 의견·상태·작성자·시각
```

모든 저장 객체는 비공개입니다. 영상과 기관별 조회는 서버에서 권한을 확인합니다. 의견은 파일을 덮어쓰지 않고 각각 저장해 동시 등록에 따른 의견 손실을 줄입니다. 최신 의견의 상태를 현재 상태로 표시합니다. 다른 브라우저의 변경은 화면 새로고침 시 반영됩니다. 실시간 공동 편집이나 자동 폴링은 포함하지 않았습니다.

소규모 운영을 위한 구조입니다. 목록 조회는 관련 JSON을 읽으므로 영상·의견 수가 커지면 조회 비용과 시간이 증가합니다. 대규모 운영에는 검색·페이지 처리와 전용 DB 도입을 검토해야 합니다. 영상 삭제 후에도 검수 기록은 이력으로 남습니다. 업로드 도중 연결이 끊기거나 정보 저장이 실패하면 Blob에 등록되지 않은 원본이 남을 수 있어 Storage에서 정리할 수 있습니다.

## 로컬 실행

Node.js 24와 pnpm 11.25.0을 설치한 환경에서 실행합니다.

```sh
pnpm install --frozen-lockfile
# .env.example을 .env.local로 복사하고 Vercel 환경 변수 설정
pnpm dev
```

Vite 개발 서버에도 동일한 API를 연결했습니다. 환경 변수 없이 화면을 볼 수 있지만 로그인·영상 저장에는 실제 Private Blob 설정이 필요합니다. `pnpm preview`는 정적 결과만 제공하므로 API 전체 검증은 `pnpm dev`나 Vercel에서 진행하세요.

```sh
pnpm lint
pnpm test
pnpm build
```

## 확인 결과와 배포 후 확인 사항

타입 검사와 프로덕션 빌드를 통과했습니다. 인증, 기관·영상 격리, 의견 동시 등록, 권한 없는 업로드 차단, 타임코드 재생의 범위 계산을 자동 테스트합니다. API 테스트는 실제 결제·저장소 변경 없이 Blob을 메모리 대역으로 치환합니다. 로컬 브라우저에서 진입·로그인 화면의 렌더링과 경로 이동을 확인했습니다.

운영 주소에서 관리자 로그인, Private Blob 읽기·쓰기, 기관 프로젝트 저장, 제출 링크 생성, 다른 기관 접근 차단, 변조 토큰 거부와 로그아웃을 확인했습니다. 실제 강의 파일은 제공되지 않아 영상 업로드·실기기 재생·인쇄 QR 스캔은 아직 확인하지 못했습니다. 작은 MP4를 등록해 다음을 확인하세요.

1. 관리자에서 프로젝트·영상을 생성하고 다른 브라우저에서 링크를 엽니다.
2. 모바일에서 재생·구간 이동을 확인합니다. 비공개 영상은 서버를 거쳐 범위 요청당 최대 8MiB로 스트리밍합니다. 느린 연결에서는 함수 실행 시간 제한의 영향을 받을 수 있습니다.
3. 검수 의견을 저장하고 관리자에서 새로고침하여 기록·상태와 CSV를 확인합니다.
4. 개별 링크의 `p`, `v` 값을 바꿨을 때 다른 프로젝트·영상이 열리지 않는지 확인합니다.
5. QR PNG를 내려받아 실제 스마트폰으로 스캔합니다.

무료 오픈소스 도구로 개발했습니다. Vercel 호스팅·함수·Blob 저장·다운로드에는 플랜 조건과 사용량 제한이 적용되므로 무제한 무료 운영을 보장하지 않습니다. 특히 비공개 영상 재생은 Blob 전송과 함수 사용량이 발생합니다. 회사 업무용 배포의 플랜 적합성을 확인하고 예산 알림을 설정하세요.
